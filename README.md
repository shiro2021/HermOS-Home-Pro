# HermOS Home Pro

HermOS is a Genode/NOVA-based operating system directed by the Hermes agent.
This is the **Home Pro** edition (consumer desktop).

## Layout

| Path | Contents |
|---|---|
| `repos/hermos/` | HermOS components — `desktop_builder`, `theme_engine`, `hermos_files`, `agents_sidebar`, `hermes_agent`, support libs |
| `tools/` | Build, release, and QEMU automation |
| `docs/` | Design documents and concept art |
